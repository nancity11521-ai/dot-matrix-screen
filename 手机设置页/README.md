# 点阵屏设置交互网页版

依据已确认的白光设置页效果图和《手机点阵屏设置功能说明》制作。作为独立的手机交互体验页面，未替换现有点阵模拟器。

## 已实现
- 首页：白光实时预览、总开关、六分类横向滑动，初始四项。
- 更换样式：点击勾选，再次点击取消；系统含倒计时、通知动画。
- 表情：日常心情、灵动互动、陪伴时光三个集合，每组六个，随机且不连续重复。
- 场景显示：来电、紧急提醒、充电、音乐、闹钟、计时结束；应用选择、动画选择、模拟触发及系统状态开关。
- 显示规则：白光亮度、点亮方式、时长、分隔点闪烁、定时关闭、免打扰、闹钟例外、低电量暂停。
- 倒计时：1–99 分钟，开始、暂停、继续、取消，离开页面后持续计时，归零停止。
- 音乐：本地文件播放，使用 Web Audio 实时频谱驱动点阵预览。
- 便捷工具：模拟步数与目标、方位滑杆、可持续到首页的户外警示模式。
- 自定义：393 点绘制、橡皮擦、清空、添加/复制/删除帧、播放速度、预览与保存。
- 我的动画：作品与收藏、重命名、复制、应用、JSON 导入导出和作品删除确认。

## 数据与边界
- 动画预览复用现有模拟器的 90 款定义与逐帧点阵数据。显示始终为白光。
- 设置、收藏和作品保存在本浏览器，存储键为 DOT_SETTINGS_INTERACTIVE_V1。
- 系统通知、充电、步数、传感器和硬件通信未接入；相应页面明确提供模拟体验。
- 不向原模拟器的全站动画库执行删除；此页面的作品管理仅作用于体验页自建作品。
- 定时关闭、系统免打扰等为可配置规则，真实后台触发由手机原生端实现。
- 原手机模板的设备框、手势、键盘、安全区与设备选择器均保留。
