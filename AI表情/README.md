# AI表情点阵屏 · 393 物理点阵模拟器与定制器

基于 [x.ai Grok](https://x.ai/) 灵动球开源内核 [jeremy-prt/bloub](https://github.com/jeremy-prt/bloub)（在线版：[bloub.vercel.app](https://bloub.vercel.app/)），将其数学模型与动态姿态全量重构并适配至 **393 颗物理圆形微密点阵屏** 的 Web 模拟器与硬件开发工具。

---

## 📸 项目特性

- **393 颗高密对称圆阵**：精确对应 0707CSP Φ20.00mm 物理灯板，23 行对称分布，共 393 颗发光灯珠。
- **16 种情绪表情全量映射**：平静、专注、惊讶、兴奋、开心、大笑、生气、难过、害怕、怀疑、困惑、好奇、得意、羞怯、无趣、困倦。
- **14 种动作状态与形变循环**：待机呼吸、思考沉思、俏皮眨眼、睁大双眼、警觉凝视、消息提示、感叹唤醒、深度睡眠、椭圆律动、六边晶格、弹跳趣味、行星环绕（Orbit 环带）、粒子爆发（Burst 爆裂）、彗星飞掠（Comet 流光）。
- **实时 3D 视线交互追踪**：鼠标在屏幕移动时，AI 球的双眼与头部倾角在 3D 空间球面上实时跟踪注视。
- **自然生命力动力学（Liveliness）**：拟真自然眨眼、缓慢自主呼吸起伏、微小视线游走。
- **4 种点阵呈现模式**：
  1. `大眼特写面部`（Face Focus）
  2. `完整球体剪影`（Full Blob）
  3. `高亮反相模式`（Invert）
  4. `线框轮廓模式`（Contour）
- **像素渲染算法**：支持 `PWM 拟真灰度` 与 `纯二值物理 0/1 点阵`（带阈值调节）。
- **双模并列对比**：左侧为 393 物理点阵渲染，右侧为 Bloub 原版矢量 SVG 连续渲染，动作完全同步。
- **嵌入式单片机代码导出**：
  - 50 字节 C 语言位图数组：`const uint8_t PROGMEM BLOUB_FRAME_393[50]`
  - 23 行独立 uint32_t 行掩码：`const uint32_t PROGMEM BLOUB_ROWS[23]`
  - JSON 完整动画序列导出与高清 PNG 点阵截图。

---

## 🛠️ 物理硬件规格参数

- **芯片规格**：0707CSP / 393PCS / 间距 0.16mm / Φ20.00mm 圆形物理灯板
- **阵列排列**：23 行微密对称圆阵
- **每行灯数**：
  ```
  5, 9, 13, 15, 17, 19, 19, 21, 21, 23, 23, 23, 23, 23, 21, 21, 19, 19, 17, 15, 13, 9, 5
  ```
- **总灯数**：5×2 + 9×2 + 13×2 + 15×2 + 17×2 + 19×4 + 21×4 + 23×5 = **393 颗**
- **中心坐标**：以 (11, 11) 为物理中心基准。

## 🚀 本地运行

该页面为 100% 纯原生自包含网页（HTML5 Canvas + SVG + Vanilla JS），无任何外网 CDN 或 node 构建依赖：

直接在浏览器中打开 `index.html`，或在当前目录下启动本地静态服务：

```bash
# Python 快速启动
python3 -m http.server 8888
```

然后在浏览器打开 `http://localhost:8888` 即可体验。
