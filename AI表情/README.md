# 点阵屏项目 · 393 物理点阵全场景动画定制平台

基于 **393 颗物理圆形微密点阵屏**（23×23 对称圆阵，0707CSP Φ20.00mm，固定高亮纯白光）打造的全场景硬件动画开发、模拟与嵌入式代码生成平台。深度适配 **传音 Infinix Note 60 Pro (5G)**（内部代号 GR1003）整机点阵屏体系，并兼容多场景通用点阵显示系统。

## 🛠️ 硬件与像素控制

- **4 种点阵呈现模式**：大眼特写面部（Face）、完整球体剪影（Blob）、高亮反相（Invert）、边缘轮廓（Contour）。
- **像素发光算法**：支持 **PWM 拟真灰度** 与 **纯二值物理 0/1 点阵**（带阈值调节）。
- **LED 物理光效**：固定高亮纯白光（传音标准白光），支持调色盘自定义发光（麦金、冰蓝、极客绿、暗夜红等）。
- **硬件动态输入模拟**：支持在左侧面板动态拖动调节电量、音量、温度与罗盘角度，点阵屏实时联动更新。

## 🚩 待修改项全端同步与持久化体系 (v2.8.0)

为确保评审与协作过程中标记的待修改动画永不丢失，系统构建了**三重防丢保障体系**：
1. **线上代码基准默认同步 (`DEFAULT_PENDING_IDS`)**：内置 21 款重点待优化动画代码基准，初次打开 100% 自动带出。
2. **URL Hash 状态实时流转 (`#pending=...`)**：点击卡片静默同步 URL，移动端微信或下拉刷新绝不丢失。
3. **多层本地持久化与配置导出**：LocalStorage V10 自动向上迁移，提供分享链接与配置导出功能。
