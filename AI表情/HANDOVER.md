## 一、项目核心背景与产品定位

### 1.1 硬件规格指标
- **屏幕形态**：直径 **20.00 毫米 (Φ20mm)** 的超小圆形发光盘，约与 1 元硬币大小一致。
- **发光核心**：密密麻麻排列着 **393 颗微型发光 LED 小灯珠**（0707CSP 微型器件，点间距约 0.16mm）。
- **几何排列**：**23 行上下轴对称圆阵**，从最顶部 5 颗灯逐渐放宽至中央第 11 行最宽 23 颗灯，再平滑收紧至底部 5 颗灯。
- **物理发光颜色**：经典复古暖阳麦金黄光（`#facc15` / `#ffd45e`），支持在界面随心换色（赛博蓝、极客绿、暗夜红等）。

### 1.2 左右双视窗同频架构
- **左视窗（点阵发光屏）**：模拟真实 393 颗物理灯珠的圆盘排布，支持 PWM 拟真灰度发光与 0/1 二值化发光，带有柔和外散光晕。
- **右视窗（普通高清屏）**：展现 60 FPS 连续高保真彩色矢量画面，用于设计审美与精细动效对比。
- **同频联动**：左右双视窗由同一个毫秒级时间基准驱动，动作、节拍、滑块调节 **100% 毫秒同频锁定**。

### 1.3 纯原生零依赖架构
- **零构建、零 npm**：项目完全由纯 HTML5 + CSS3 + Canvas 2D + ES6+ 编写。
- **即开即用**：双击 `index.html` 即可直接在任何现代浏览器中运行，离线可用。

### 核心函数详解

1. **`PHYSICAL_POINTS` (L1495)**:
   - 包含 393 个物理灯珠对象的数组。
   - 每个对象包含：`idx`（0~392 物理序号）、`r`（0~22 行）、`c`（该行列号）、`x`/`y`（归一化几何坐标 -1.0 ~ +1.0）、`gridId`（`r*23 + c` 唯一网格标识）。
2. **`refinedFrame(kind, frame, opt)` (L1550)**:
   - 栅格动画（SYS / ACT / LIF / AMB）的点阵生成函数。
   - 输入动画标识 `kind`、当前帧 `frame`、选项 `opt`。
   - 返回一个 `Set`，存储当前帧点亮的灯珠网格 ID。
   - 内部封装了 `put(x, y)`、`line(x1, y1, x2, y2)`、`box(x, y, w, h)`、`circle(cx, cy, r)`、`mask(str, x, y)`、`text5x8(str, y)` 等工具函数。
3. **`evaluateAvatarFrame(time, anim)` (L3745)**:
   - 驱动 36 款 EMO 表情的核心 3D Avatar 数学模型。
   - 计算注视追踪、自然呼吸起伏、随机眨眼闭合度、眼皮形变与瞳孔位移。
4. **`renderNormalDisplay(anim, curTime, frameData, opt, customFrameSet)` (L4093)**:
   - 右侧高清矢量圆盘渲染器。
   - 包含所有官方动画的 Canvas 2D 高保真矢量代码实现（表盘、曲线、光晕、数字等）。

### 4.2 传音 Infinix Note 60 Pro (5G) 专属定制点阵体系（内部代号 GR1003）

根据《GR1003点阵屏需求文档_新模板版》与《点阵屏灯效需求文档_最新版》，为传音 Infinix Note 60 Pro（5G）手机打造了完整的硬件与交互对齐体系。

#### 1. 硬件规范与设计定义
- **硬件形态**：23×23 网格内圆形排布 **393 颗固定单色高亮白光 LED**，纯白发光，无彩色杂质。
- **页面风格**：浅灰页面底色、白色圆角卡片、绿色品牌强调色，Pixel/透明手势导航适配。
- **亮度与走时**：亮度 10%～100%（默认 80%），时间显示上下时分字模适度收窄，中间 5 点紧邻连续排列并支持每秒同步闪烁。

#### 2. 显示优先级与调度体系 (P0 ~ P6)
系统任意时刻仅显示一个场景，高优先级即时抢占低优先级，事件结束后重新选择仍有效且允许显示的最高等级场景恢复：

| **P1** | **闹钟及计时结束** | `ALARM` (#68), `FOCUS` (#52) | 优先于通知和普通灯效；来电期间暂缓；同级先触发先显示，闹钟优先；计时结束补播一次 | 闹钟随事件 / 计时结束 5s |

## 六、Codex / Cursor 二次开发实操手册

### 6.1 场景一：修改已有动画（如调优某款动画的造型与速度）
1. **修改点阵屏算法**：
   - 打开 `index.html`，定位至 `function refinedFrame(kind, frame, opt)`（约 **1550 行**）。
   - 找到对应 `case 'ANIM_ID':`，修改其网格点亮坐标。
2. **修改右侧高清矢量屏**：
   - 定位至 `function renderNormalDisplay`（约 **4093 行**）。
   - 找到对应 `case 'ANIM_ID':`，修改其 Canvas 矢量绘制逻辑。

### 6.2 场景二：新增一款全新动画
若要新增第 85 款动画（例如 `#85 · AMB-09 流星雨 METEOR`）：
1. **在 `DEFAULT_ANIMATIONS` 中注册元数据**（约 **3000 行**）：
   ```javascript
   { num: '#85', no: 'AMB-09', id: 'METEOR', name: '流星雨', cat: 'ambience', subcat: 'visual', icon: '🌠', frames: 24 }
   ```
2. **在 `refinedFrame` 中实现点阵绘制**（约 **1600 ~ 2900 行**）：
   ```javascript
   case 'METEOR': {
     const t = frame;
     line(t, 2, t + 4, 6);
     break;
   }
   ```
3. **在 `renderNormalDisplay` 中实现高清矢量绘制**（约 **4100 ~ 4500 行**）：
   ```javascript
   case 'METEOR': {
     ctx.beginPath();
     // ...
     ctx.stroke();
     break;
   }
   ```
4. **在 `docs.html` 中同步更新需求文档表与版本号**。

### 6.3 场景三：管理与解除「待修改」标记 (Pending)
- **代码基准位置**：`index.html` 约 **3117 行** 的 `DEFAULT_PENDING_IDS` 数组。
- 当某款动画修改完毕后，只需：
  1. 在 `DEFAULT_PENDING_IDS` 数组中删去该 ID；
  2. 在 `DEFAULT_ANIMATIONS` 中删去该项的 `isPending: true`；
  3. 页面重新加载后即自动变为正常非待修状态。

### 6.4 常用点阵绘图 API 查阅表 (23×23 几何坐标系)
- `put(x, y, on = true)`：点亮或熄灭单个坐标灯珠（超出圆形边界自动安全忽略）。
- `line(x1, y1, x2, y2, on = true)`：画线（两点之间自动插值）。
- `box(x, y, w, h, fill = false)`：绘制矩形框或实心矩形。
- `circle(cx, cy, r, fill = false)`：绘制圆形或圆环。
- `mask(str, x, y)`：用 `/` 分隔的位图字符串贴图（如 `'1111/1001/...'`）。
- `text5x8(str, y)`：在指定 y 行居中绘制 5×8 大字模数字字符串。

## 七、单片机 C 语言驱动与导出规范

在右侧栏点击「导出代码」面板，可一键获取当前帧或整套动画的单片机代码：

```c
// ========================================================
// 393 点阵屏动画位图数据包 (50 字节紧凑位图编码)
// 适用硬件：23x23 对称圆阵，393 颗单色/双色微型发光二极管
// 格式：每位 (bit) 代表一颗灯珠 (1=亮, 0=灭)，共 393 位 = 50 字节
// ========================================================
const uint8_t PROGMEM FRAME_DATA[50] = {
  0x00, 0x1F, 0x00, 0xFE, 0x01, /* ... 50 字节 ... */
};
```

- **单片机驱动逻辑**：MCU 在按行扫描驱动点阵时，只需依次取出 50 字节中的每一位输出到对应行驱动引脚即可，内存开销极低（1 秒 12 帧仅需 600 字节 ROM）。
